========================================================================
             AI 暗水印与明水印消除系统 - 离线与本地使用说明
========================================================================

【特别提醒：为什么直接双击 index.html 会显示空白页面？】
本工程是由 React + TypeScript + Vite 构建的现代前端工程。
根目录下的 index.html 中引用的是未经编译的 /src/main.tsx 源码文件。
浏览器在直接双击本地文件（file:// 协议）时出于安全策略会拦截模块加载，
且浏览器无法直接运行未编译的 TypeScript 代码，因此会显示空白。

------------------------------------------------------------------------
🌟【方式一：最简单推荐！免安装单文件离线版（真正双击即用）】
------------------------------------------------------------------------
如果您不想安装 Node.js、不想在命令行敲代码，请直接使用：
👉 双击打开当前目录下的【ai_watermark_remover_offline.html】

特点：
1. 零依赖、零配置，任何电脑、任何主流浏览器直接双击打开即可使用。
2. 即使完全断网、拔掉网线，所有功能完全可用。
3. 包含完整图形界面：图片批量上传与拖拽、豆包明水印识别与内容感知抹除、
   频域 DWT-DCT 隐形暗水印自适应中和、二次上传验证、前后滑动对比、下载净化图。

------------------------------------------------------------------------
💻【方式二：本地运行完整开发版（Node.js / Vite 模式）】
------------------------------------------------------------------------
如果您希望在本地运行完整的 React + Vite 交互系统：

1. 确认电脑已安装 Node.js (https://nodejs.org)
2. 快速启动方式：
   - Windows 用户：直接双击【一键启动_Windows.bat】
   - Mac / Linux 用户：终端运行【./一键启动_Mac_Linux.sh】
3. 或手动在当前文件夹打开终端输入：
   npm install
   npm run dev
4. 打开浏览器访问：http://localhost:3000

------------------------------------------------------------------------
🐍【方式三：Python 纯脚本批量处理（适合几十上百张批量任务）】
------------------------------------------------------------------------
如果您需要后台无人值守自动批量处理海量图片：
1. 安装 Python 依赖：
   pip install -r requirements.txt
2. 将需要处理的图片放入 input_images 文件夹中
3. 运行批处理脚本：
   python ai_watermark_remover.py
4. 处理完毕后，干净图片将保存在 output_images 文件夹中。
